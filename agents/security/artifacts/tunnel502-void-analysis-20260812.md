## 一、TUNNEL-502 空窗定义与成因

- **脚本语义**（`tools/monitor_phishing.py`）：`CONNECT host:port` 到 webshare 代理隧道，若代理层未返回 `200`，则该目标状态记为 `TUNNEL-<code>`（如 TUNNEL-502）或 `TUNNEL-FAIL`（隧道建立失败/无响应）。
- **本质**：这是 **webshare 住宅代理 → 目标之间的隧道层（代理链路）间歇错误**，**并非目标站点下线**。证据链见下。
