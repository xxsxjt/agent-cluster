## 二、可直接派发的任务清单（按优先级）

### 🟥 P0 建议立即派发（工作量小、快速闭环、能立竿见影）

**任务 A：plantmagic 待修问题清单落地修复**（执行：mc-dev-plantmagic）
基于 08-10 盘点已确认的 5 项问题，本可立即推进：
1. **P0 lang 命名空间错位**：`src/main/resources/assets/dmnr/lang/zh_cn.json` 误放"神龙魔法与遗物(DM&R)"mod 的 300+ 翻译条目，与本 mod（`plantmagic_fixes`）无关，纯冗余占用 → 删除冗余 + 建立本 mod 语言文件
2. **P1 缺 en_us.json**：assets 下无本 mod 语言文件 → 补建
3. **P1 无版本库**：项目根目录无 .git → 补建 .git（参照 earth_human_body 做法），改坏可回滚
4. **P2 mods.toml 隐式依赖未声明**：实际依赖 portlib/terra_curio 但未声明 → 加 optional 依赖提示
5. **P2 mixins 注册注释**：补充扩展说明

→ 建议优先级：P0 > P1 > P2；预计一轮可完成 P0+P1。

### 🟧 P1 建议排期派发（需明确方向后推进）

**任务 B：虚无圣殿 beta.4 方向推进**（执行：mc-dev-temple）
beta.3 基线健康（63 物品/15 方块/5 生物/97 配方/三武器动作/三级仪式/虚空宝库/传输核心，74 JUnit + 481 双语键门禁），下阶段目标为**在 beta.3 基线上选取 1-2 个高优先级未完成项**（衔接 backlog mc-continue）。候选方向（需管理组/用户选定其一）：
- B1 新内容扩充（新物品/方块/生物/维度）
- B2 平衡性调整与既有机制完善
- B3 背景设定落地为 mod 内容（结合创意/世界观）
- 纪律：每次改动即 commit，杜绝再出现"264 项未提交"风险；维护 74 JUnit + 481 双语键门禁

→ 需管理组从 B1/B2/B3 中拍板 1 个方向并明确范围后派发。
