TEMPLE OF NIHILITY

虚无圣殿 · Temple of Nihility

Minecraft 26.2 / NeoForge 26.2.0.7-beta 内容扩展模组。虚无、虚空、混沌、深渊四系设计；圣殿建筑、武器装备、虚无宝库与归零祭坛。开发中测试版，不建议直接用于长期主存档。

世界观与四系设计

模组围绕四种概念体系展开，各自有明确的视觉与功能边界：

  • 虚无：本质与归零——空寂石、虚无残片、归尘、虚无核心
  • 虚空：空间与传输——虚空宝库、虚空终端、常加载区块
  • 混沌：仪式与进阶——混沌共鸣核、归零祭坛
  • 深渊：生物与交易——深渊生物交易系统

核心功能

  • 虚无圣典：原版书本界面的游戏内指南，介绍圣殿、祭坛图、生物、宝库与游玩流程。
  • 四系材料：虚无残片、归尘、空相结晶、圣殿符文、虚无核心、混沌共鸣核。
  • 圣殿建筑：空寂石系方块、圣殿符文砖、虚空灯、虚空玻璃、归零祭坛。
  • 武器工具：匕首「缺位步」、剑「归零斩」、巨刃「断界式」，以及镐、斧、铲、锄。
  • 装备：虚无头盔、胸甲、护腿、靴子；Curios 饰品（戒指、项链、腰带、披风、手甲、时沙计、魂锚等）。
  • 虚无宝库：多方块仓储网络，每库 243 格；相邻同主宝库自动合并，带访问保护。
  • 虚无终端：随身饰品栏开启，默认 O 键打开已绑定的宝库网络；支持常加载（默认每网络 9 区块）。
  • 归零祭坛：多方块仪式核心，按结构等级把材料进阶为结晶、符文、封印和核心。
  • 主动道具：灯核、复苏宝珠、遁影符、净化铃、洞察镜、屏障核、相位羽、引力符、战号。
  • 虚无状态：自定义「遁入虚无 / 融于虚无 / 隐入虚无」，不再使用原版隐身。

玩家入口

  • 一本书 + 空寂石 / 虚无残片 / 归尘任一种 → 合成《虚无圣典》。
  • 默认 O 键打开携带或佩戴的已绑定虚空终端。
  • 正常玩法不需要聊天命令；/temple 仅保留给管理员调试生成结构。
  • 归墟匕首右键：缺位步；归零之刃按住蓄力：归零斩；断界巨刃右键：三段断界式。
  • 手持虚空终端潜行右键虚空宝库：绑定终端；终端界面可切换整个宝库网络常加载。
  • 归零祭坛：I 级（四向符文砖）、II 级（四角虚空水晶块）、III 级（圣殿柱 + 錾制空寂石）。

开发路线

  • 四系设计准则：虚无、虚空、混沌、深渊的概念、视觉和功能边界。
  • 开发路线图：长期版本计划、内容矩阵和发布门槛。
  • 功能质量契约：按六个可玩纵向闭环定义权威状态、玩家表面与完成证据。
  • 自定义动作系统：武器技、生物招式、仪式动作和同步/性能规则。
  • 传输系统：定向路由、过滤、红石、吞吐、迁移和验证边界。
  • 探索与居民：神龛代表结构、和平开局、居民状态和行为边界。
