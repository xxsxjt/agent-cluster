xxsx-api 文档

xxsx-api 是 xxsxjt 旗下的多供应商 AI 代理网关（OpenAI / Anthropic / DeepSeek 协议兼容）。本文档收录接口约定、运维手册与部署说明。

1. 连接格式转换器

本地接口：POST http://127.0.0.1:3461/api/connection-formats/convert

鉴权请求头：X-XXSX-Local-Key

输入

支持直接粘贴 xxsx-api 兼容连接对象，或拆开传 url / key / model / name 字段。

{ "url": "http://localhost:3461", "key": "sk-agnes-local-proxy-v1", "model": "gpt-4o-mini", "name": "xxsx local" }

输出

返回转换后的目标格式连接对象（newapi / openai / anthropic 等），供客户端直接使用。

2. MI 节点变体部署

xxsx-api 支持以 MI 数据节点变体方式部署，用于承载记忆与情报数据服务（xxsx-api-mi）。

  • 部署形态：systemd 服务 xxsx-api-mi.service
  • 服务端口：127.0.0.1:3461（new-api 兼容）
  • 数据：mem / kno 双库，通过渠道留痕持续增量更新

3. Edge 网络会话收集器

面向浏览器扩展与远程节点的会话数据收集器，负责把 Edge 扩展产生的会话流接入 xxsx-api 通道。

  • 会话格式：按设备 / 会话分组，支持断点续传
  • 接入点：通过 xxsx-api 统一鉴权后写入
  • 用途：对话即蒸馏——把分散会话沉淀为可检索的知识

4. 接口约定

  • 协议：OpenAI / Anthropic / DeepSeek 兼容
  • 入口：https://api.xxssxx.top/v1（Tailscale 内网）
  • 管理：new-api 控制台（仅内网可达）
  • 客户端：xxsx-api-android（用户端 / 管理端）

详细接口文档随版本更新，以仓库 docs/ 目录为准。
