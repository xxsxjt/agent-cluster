# 【抖音/快手 小说推文口播文案模板】

（以下模板用于制作小说推文视频的口播文案）

模板1：悬念开场型
「他是个拾荒者，所有人都说他活不过这个冬天。
直到那天，他在废墟中发现了一块暗紫色的石碑。
碑上的螺旋纹路开始发光——
那一刻，他的双眼变成了深紫色。
从那天起，再也没有人敢欺负他。
因为他的眼睛，就是武器。」

模板2：冲突开场型
「擂台上，所有人都嘲笑这个瘦弱的拾荒者。
对面是铁壁城最强的战士秦昊，浑身散发着灰色气场。
苏铭没有说话，只是抬起了眼睛。
那一瞬间，所有人都感觉到了恐惧。
因为那双眼睛里，藏着比废土更深邃的力量。」

模板3：反转开场型
「她是个普通人，没有任何灵气。
但她有一双能看透一切的眼睛。
当幽界的军队攻破城墙时，
当所有人都在逃跑时，
只有她看到了真相——
那些怪物，其实害怕的是苏铭的眼睛。」

使用说明：
1. 选择模板，替换角色名和情节
2. 每条视频控制在15-60秒口播
3. 配合AI生成的画面使用
4. 结尾留悬念，引导看下一集
