第二部分：三条变现路径（按优先级排序）
================================================

================================================
路径 A：小说推文 → 短视频平台分成（最快）
================================================

核心逻辑：
  将小说改编为短视频推文 → 发布到抖音/快手 →
  赚取平台流量分成 + 小说推广佣金

收入来源：
  1. 平台流量分成：抖音中视频计划（约 2-10 元/万播放）
  2. 小说推广佣金：挂小说链接，读者付费后分成 30%-50%
  3. 平台补贴：快手/百度的创作者激励计划

投入成本：
  - API token：每个视频约 0.5-2 元
  - 时间：每个视频约 1-2 小时

收益预期：
  - 新手期（1-2个月）：月入 500-2000 元
  - 稳定期（3-6个月）：月入 3000-10000 元
  - 爆款视频（单个）：可达 10 万+ 播放，单条分成 200-1000 元

执行步骤：

  第1步：注册平台账号（1天）
    - 抖音：douyin.com → 创作者中心 → 申请中视频伙伴计划
    - 快手：kuaishou.com → 创作者平台
    - B站：bilibili.com → 创作中心
    - 微信视频号：微信内搜索"视频号助手"
    - 重点：完成实名认证

  第2步：选择小说来源（1天）
    - 自有小说《再看，就把你瞪死》（已具备剧本）
    - 番茄小说/七猫：免费授权小说
    - 推荐：先用自有小说练手

  第3步：制作第一批视频（3-5天）
    - 使用 video-project/ 管线生成视频
    - 每条 1-3 分钟
    - 日更 1-2 条，连续 5-10 条建立账号权重

  第4步：挂载小说链接（同步第3步）
    - 抖音：中视频伙伴计划挂载番茄小说链接
    - 快手：磁力聚星挂载小说推广
    - B站：简介区挂小说链接

  第5步：分析数据，优化内容（持续）
    - 关注完播率（目标 > 30%）
    - 关注点赞率（目标 > 3%）

注意事项：
  - 不要搬运他人作品
  - 避免敏感内容
  - 小说推文需有合法授权或为自有作品

================================================
路径 B：接 AI 视频制作外包（中期）
================================================

核心逻辑：
  用你的视频管线为别人制作 AI 视频 → 收取服务费

收入来源：
  1. 闲鱼接单：AI 视频定制，每条 200-500 元
  2. 小红书获客：发布作品 → 客户主动找你
  3. 猪八戒/一品威客：正规外包平台
  4. 直接对接品牌方

收益预期：
  - 新手期（1个月）：月入 1000-3000 元
  - 稳定期（3个月）：月入 5000-15000 元
  - 大单：预告片/宣传片 3000-10000 元/个

执行步骤：

  第1步：准备作品集（2-3天）
    - 完成预告片（展示实力）
    - 制作 5-10 条不同风格样片
    - 上传 portfolio.html

  第2步：注册接单平台（1天）
    - 闲鱼：搜索"AI 视频制作"，研究竞品
    - 小红书：标签 #AI视频 #AI绘画
    - 豆瓣小组：搜索"视频制作""外包"

  第3步：定价策略
    - 入门单（200-300元）：15-60秒短视频
    - 标准单（500-1000元）：1-3分钟视频
    - 高单价（2000-10000元）：预告片/宣传片
    - 策略：前3个客户打折换好评

  第4步：交付流程
    - 第1天：沟通需求，收 50% 定金
    - 第2-3天：制作，发预览
    - 第4-5天：修改 + 交付，收尾款

注意事项：
  - 一定要收定金！
  - 明确修改次数
  - 用 portfolio.html 展示专业形象

第四部分：关键提醒
================================================

1. 不要追求完美。第一个月目标是"跑通流程"。
2. 保持日更。算法奖励持续更新的账号。
3. 先量后质。先做出 30-50 条视频，再提升质量。
4. 不要怕花钱。每个视频 1-2 元 token，换来 200-500 元收入。
5. 不要卖代理。转售 API 访问权违反 Agnes AI 服务条款。
