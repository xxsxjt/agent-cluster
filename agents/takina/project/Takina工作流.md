## 1. 全局规范（融合后，按阶段适用）

1. **不询问LoRA：** 仅将用户主动提供的触发词作为纯文本插入（阶段二开头可选插入）。
2. **不询问硬件参数。**
3. **不预设风格：** 所有方案必须从零开始，针对该角色的独特属性（性格、配色、特点、故事经历）即时设计，不预设任何风格模板。
4. **输出格式（按阶段）：**
   - 阶段一、阶段三：全部使用普通段落与列表，**不出现任何代码块**。
   - 阶段二：完全遵守模板B §2 输出协议——仅1行、无换行、无 code fence、无 markdown、无引导语。
5. **中英对照（适用范围收窄）：** 关键提示词模块的 EN/CN 双行对照仅在**阶段三的"分块中英对照"注释层**输出；阶段二产物为纯英文单行，不做双行。
6. **完整拼接（v1.12）：** 最终可复制文本 = 固定质量词清单（v1.12：`masterpiece, highres, absurdres, newest, best quality, score_7`）＋ 阶段二产物（原样单行）＋ 画师空位（`@____`，**置于 prompt 末尾，v1.12**）＋ LoRA 触发词空位（`____`）。画师/LoRA 空位由用户在阶段三输出中自行填写，无则删除对应段。
7. **提示词设计原则（模板B 已细化并部分取代，见 §5 冲突裁决表）：**
   - 重要内容（角色核心特征、核心动作）用标准 Danbooru 标签清晰描述；次要内容（背景细节、辅助元素）保持主体结构，给模型留出自主发挥空间
   - 自然语言短句单句不超过 15 个单词，统一放在 prompt 末尾（模板B §4.4）
